# M0 address-identity browser characterization

This suite records a published-baseline integrity failure without changing
product code. It runs in a real Chromium browser against the Vite development
build and crosses the actual worker, renderer texture/offscreen probe,
IndexedDB, reload, and download boundaries.

## Install and run

```sh
npm ci
npx playwright install chromium
npm run typecheck:browser
npm run test:browser:harness
npm run test:browser
```

`test:browser:harness` must pass. On the baseline commit `7af2394`, the full
suite must fail only in the two characterization scenarios described below.
The branch is intentionally evidence-only and must not be merged while red.

## Fixed cases

### Generated address

- Coordinate: `000102030405060708090a0b0c0d0e0f`
- Format: plane, 2×2, RGB16, 12 rounds
- Exact 24-byte address:
  `c96db2c925092257354f0d818edf7c9bbc43e60eda65194d`

The test materialises and persists the address, removes URL-carried identity,
reloads from IndexedDB, exports UIA2, and reloads again. The first reload keeps
the bytes but loses the complete generated identity. Export then substitutes
new generated bytes and writes them to the worker, renderer texture, download,
URL, and IndexedDB; the second reload restores the substitution.

### Imported address

- Format: plane, 2×2, RGB16
- Exact 24-byte UIA2 payload:
  `fedcba98765432100f1e2d3c4b5a69788796a5b4c3d2e1f0`

The test imports a valid 44-byte UIA2 file, persists it, removes URL-carried
identity, reloads from IndexedDB, exports, and reloads again. The same failure
occurs: opaque provenance is lost, then export substitutes unrelated generated
bytes and permanently replaces the only persisted copy.

The substituted bytes are intentionally not golden values: the hidden seed is
random on each browser start. Every failing run prints the original and actual
worker, renderer, download, URL, identity, and IndexedDB evidence as hex/JSON.

## What the tests prove—and do not prove

The passing harness proves that automation reaches live app boot, the renderer,
real Worker RPC, real IndexedDB transaction completion, and a real browser
download with an exact UIA2 header and payload. The two red tests add reload and
byte-for-byte corruption assertions for generated and imported addresses. The
visual oracle is an offscreen readback through the real WebGL2 address texture
and shader pipeline; it is deliberately not described as a canvas screenshot.

This suite does not fix the defect and does not characterize crypto, P2P,
permalinks, protocol ADRs, head stepping, or unrelated experimental modules.
